# rpm packaging files for NCL

This github repository neither hosts nor provide ncl sources, it's meant to
host (unofficial) convenience files for EPEL 10 rpm packaging.

See:
- https://bugzilla.redhat.com/show_bug.cgi?id=2531341
- http://www.ncl.ucar.edu
- https://github.com/NCAR/ncl
